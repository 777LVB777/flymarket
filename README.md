# Flymarket

Public website for a preregistered computational study: can a simulated fruit-fly brain circuit (the Shiu et al. 2024 connectome model, plus a reward-learning rule added to its mushroom body) learn to predict market outcomes from reward alone?

- Live site: https://777lvb777.github.io/flymarket/
- Research code and preregistration: https://github.com/777LVB777/flyshi-research (working name: Flyshi)

Simulated trading only; no real money. Not affiliated with or endorsed by Polymarket. The Trading page shows placeholder data until the verdict.
