Section 4

The checks

Each check below was planned in writing before it was run. Failures and mistakes are listed alongside the passes and kept on the record.

Passed or lockedFailed, or a mistake was found
September 2026

The published model was reproducedpassed

Our copy of the model gave the same response to a sugar-feeding signal as the original paper, with the same top responding neurons.

September 2026

Smell input did not workfailed

A single smell channel spread to about 97 percent of the next layer of neurons, so different smells looked the same to the circuit. We switched to driving the Kenyon cells directly.

September 2026

Input cells came from both sides of the brainbug found

The input code was choosing cells from both sides of the brain, which caused the whole mushroom body to fire at once. We fixed it and kept the failed runs in the record.

September 28

The circuit learnedpassed

The learning effect was 154.5 against a threshold of 6.5, and all five control conditions behaved as predicted.

October 9

The market code still had the old input bugcaught before running

A check before the main run found the market simulation still using cells from both sides. It was fixed before any server was rented.

October 9

The original comparison could be passed by luckcaught before running

A power analysis showed the first benchmark could be beaten by chance alone. We replaced it with the best possible forecast based on price alone.

October 11

The server matched the laptop exactlypassed

The cloud server reproduced a saved laptop simulation exactly, down to every neuron.

October 12

Runaway firing did not explain the learning resultpassed

Removing the trials with runaway firing made the learning effect slightly larger, not smaller.

October 16

The real-market rules were publishedlocked

The pass rule, the shuffled-outcome control and the list of markets were all fixed before any price data was downloaded.

October 17

The price data was downloaded and checkedpassed

Price histories for 11,500 markets were downloaded and checked. No price in the data comes from after the moment the circuit makes its decision, and the input strengths stay within the range already tested.

October 17

The real-market test was locked to run regardless of the first resultlocked

Before any result from the simulated markets existed, we recorded that the real-market test runs whatever the simulated test shows. This removes any chance of choosing based on the outcome.

October 17

The remaining runs were automatedpassed

A program on the server now finishes the simulated test, publishes its result, and starts the real-market test on a frozen, tagged version of the code. It was tested on fake data before being switched on.
